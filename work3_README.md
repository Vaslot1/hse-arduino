# Лабораторная работа 3 — метеостанция с прогнозом погоды

## Что это вообще такое

Продолжение предыдущей работы. Домашняя метеостанция на Arduino измеряет
температуру, влажность, давление и освещённость. В прошлый раз эти
показания просто приходили на телефон. Теперь мы отправляем их ещё и
в интернет — в облачный сервис ThingSpeak. Облако хранит историю
измерений, рисует графики и раз в 5 минут само составляет простой
прогноз погоды (по давлению: выросло — будет ясно, упало — к дождю).

Второе приложение на телефоне показывает этот прогноз. Главная фишка:
оно работает откуда угодно — хоть из другого города, потому что
обращается не к нашей домашней сети, а к облаку.

## Как всё связано

```
Датчики → Arduino → Raspberry Pi → телефон №1 → облако
                                                │
                                  облако считает прогноз
                                                │
                                           телефон №2
```

1. Arduino раз в 30 секунд отправляет измерения на Raspberry Pi.
2. Приложение №1 на телефоне принимает их и пересылает в облако
   ThingSpeak — там всё складывается в «канал 1» и рисуются графики.
3. Раз в 5 минут в облаке автоматически запускается маленькая программа
   на MATLAB: она смотрит на последнее давление и пишет прогноз
   («погода будет устойчивой / облачной / дождливой») в «канал 2».
4. Приложение №2 на телефоне раз в минуту спрашивает у облака последний
   прогноз и показывает его с датой и временем.

## Что лежит в архиве

| Папка | Что это | Зачем нужна |
|---|---|---|
| `work3_2_weather_android` | Приложение №1 для телефона | Принимает показания от метеостанции и отправляет их в облако |
| `work3_3_thingspeak` | Два текста программ для облака + инструкция | `forecast_analysis.m` — считает прогноз, `channel_visualization.m` — рисует общий график; `README.md` — подробная инструкция со всеми шагами и картинками по кнопкам |
| `work3_5_forecast_android` | Приложение №2 для телефона | Показывает прогноз погоды из облака |

## Что нужно сделать, чтобы всё заработало

1. Завести бесплатный аккаунт на сайте ThingSpeak и создать там два
   «канала» (проще говоря — таблицы данных): первый — для измерений,
   второй — для прогноза.
2. У каждого канала есть секретные ключи доступа (как пароли).
   Их надо вписать в три места, где написано `YOUR_..._KEY`
   или `CHANNEL_..._ID` — в обоих приложениях и в программе для облака.
3. Тексты программ для облака копируются в веб-страницу ThingSpeak —
   ничего устанавливать не нужно.
4. Приложения устанавливаются на телефон как обычно, через Android Studio.

Подробно, с указанием каждой кнопки — в файле
`work3_3_thingspeak/README.md`.

## Что показывать на защите

Работают одновременно: метеостанция с датчиками, Raspberry Pi,
приложение №1 (пересылает данные), графики на сайте облака и
приложение №2, которое показывает автоматический прогноз погоды.
