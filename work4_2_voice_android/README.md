# Работа 4, пункт 2 — голосовой Android-клиент

Java-проект для Android Studio. Минимальная версия телефона — Android 7.0
(API 24). `compileSdk` и `targetSdk` — 35; менять targetSdk под версию телефона
для запуска не требуется.

## Открытие проекта и запуск через отладку

1. Запустите `D:\Projects\hse-arduino\Android Studio.cmd` — так используются
   уже установленные SDK и Gradle на диске D.
2. Выберите **Open** и папку
   `D:\Projects\hse-arduino\work4_2_voice_android`.
   Открывать корневую папку `hse-arduino` или отдельный `.java` не нужно.
3. Дождитесь завершения Gradle Sync. Если Studio спросит расположение SDK,
   выберите `D:\Projects\hse-arduino\android-sdk`.
   При переносе на другой компьютер выберите его SDK; `local.properties`
   Android Studio создаст сама. Для проекта настроен **JDK 21**:
   `D:\Projects\hse-arduino\tools\jdk21\jdk-21.0.12.1+1`.
   Если Studio спросит JDK, выберите этот каталог через Settings → Build,
   Execution, Deployment → Build Tools → Gradle → Gradle JDK → Add JDK.
   При переносе на другой компьютер выберите установленный JDK 17 или 21.
   Старый Lint из AGP 8.7.3 не поддерживает встроенную Java 25.
4. На телефоне: Настройки → О телефоне → нажмите «Номер сборки» несколько раз,
   пока не появится режим разработчика. Названия меню зависят от производителя.
   В параметрах разработчика включите **Отладку по USB**.
5. Подключите телефон USB-кабелем с передачей данных. На телефоне разрешите
   отладку для этого компьютера. Если телефон не виден, проверьте кабель и
   USB-режим, а при необходимости установите USB-драйвер производителя.
6. В верхней панели Studio выберите конфигурацию **app**, затем ваш телефон
   и нажмите зелёный **Run ▶**. Отдельный APK вручную собирать не требуется.
7. Телефон и Raspberry Pi должны быть в одной локальной сети. Сервер
   `server.py` должен продолжать работать во время показа.
8. В поле адреса впишите, например, `http://192.168.1.100:8000/`, заменив IP
   адресом из `hostname -I` на Raspberry Pi. Адрес сохраняется после Talk.
9. Нажмите **Говорить · Talk** и скажите `Tell me the sensor data`.

## Голос и ответы

Команды произносятся **на английском**, как в методичке. Распознавание
настроено на `en-US`, озвучивание — на `Locale.US`. Для нескольких команд
телефон сначала последовательно получает ответы, затем читает общий текст.
Также весь результат виден на экране.

Нужен установленный обработчик системного голосового ввода, обычно приложение
Google, и английский голос Text-to-Speech. В зависимости от обработчика для
распознавания может понадобиться интернет. В настройках телефона найдите
«Синтез речи» / Text-to-Speech и установите английские голосовые данные.
Проверьте громкость мультимедиа.

Приложение передаёт запись внешней системной Activity через RecognizerIntent,
поэтому само не запрашивает разрешение RECORD_AUDIO. Разрешение на микрофон
может понадобиться приложению Google или другому обработчику распознавания.

## Где какой код

- `MainActivity.java` — кнопка Talk, системное распознавание, HTTP и TTS.
- `CommandParser.java` — команды, цвета, составные фразы.
- `SpeechResponses.java` — английские фразы озвучивания.
- `activity_main.xml` — экран приложения.
- `AndroidManifest.xml` — доступ к сети, локальный HTTP, видимость обработчиков
  речи и TTS.

HTTP-команды совместимы с Python-сервером из соседней папки и основными
путями сервера в методичке: `/temperature`, `/pressure`, `/humidity`,
`/weather`, `/FF0000`, `/00FF00`, `/0000FF`, `/FFFF00`, `/FF00FF`, `/FFFFFF`,
`/000000`, `/random`.

## Если не работает

- **Нет голосового ввода:** включите обработчик речи и разрешите ему микрофон;
  используйте настоящий телефон.
- **Нет озвучивания:** установите английский голос TTS и проверьте громкость.
- **Не удалось связаться:** с телефона откройте в браузере
  `http://IP_МАЛИНЫ:8000/temperature`. Проверьте IP, работающий сервер, порт
  8000 и Wi-Fi. Гостевая сеть с изоляцией клиентов не подходит.
- **HTTP 503:** ошибка датчика или ленты; подробности в терминале Raspberry Pi.
- **Команда не найдена:** используйте фразы из общей инструкции. Например,
  `Turn on the lights, color blue` или `Turn off the lights`.

## Проверка исходников

`check-parser.ps1` проверяет разбор команд обычным Java без телефона.
Проверки компиляции и Lint:

```powershell
$env:JAVA_HOME = 'D:\Projects\hse-arduino\tools\jdk21\jdk-21.0.12.1+1'
$env:GRADLE_USER_HOME = 'D:\Projects\hse-arduino\android-data\gradle'
.\gradlew.bat :app:compileDebugJavaWithJavac :app:lintDebug
```

При этих командах отдельный APK не создаётся. Для реального запуска используйте
Run в Android Studio.
